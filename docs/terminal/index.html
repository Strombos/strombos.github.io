package

tools is the older name and takes the same subcommands.

CommandDescription
package listevery package: number, status, commands
package whatis <id|name>source, pin, commands, state
package install <id|name>|--alldownload the pinned source + dependencies
package install <source>/*install every package a source offers (e.g. cyber/*)
package update <id|name>|--allreinstall at the manifest's ref
package uninstall <id|name>delete the installed files (stays in the list)
package repo add <link> [--ref <tag|branch|sha>] [--name <name>] [--entry <file.py>] [--category <word>] [--no-confirm]
package repo remove <id|name>uninstall and forget it completely
package repo listwhere every package comes from
package source add <link|folder|file.source|name> [--ref <tag|branch|sha>]
package source remove <id|name>forget a catalog (added packages stay)
package source update [id|name]re-fetch catalogs
package source listregistered catalogs
package search [text]packages offered by the catalogs
package reloadrescan the packages folder
package doctorruntime + per-package health
Example 
package repo add https://github.com/mvt-project/mvt
package install mvt
