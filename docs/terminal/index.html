System power sys

CommandDescription
sys shutdownShut Triton down (alias: sys poweroff)
sys restartRestart Triton (alias: sys reboot)
sys logoffLock the session and show the sign-in screen (aliases: sys logout, sys lo, sys lock)
sys ptOpen the power menu in a terminal tab: Log off, Restart, Shut down (alias: sys power)

Under Triton OS, shutdown and restart act on the machine instead of just Triton.

package

tools is the older name and takes the same subcommands.

CommandDescription
package listevery package: number, status, commands
package whatis <id|name>source, pin, commands, state
package install <id|name>|--alldownload the pinned source + dependencies
package install <source>/*install every package a source offers (e.g. cyber/*)
package update <id|name>|--allreinstall at the manifest's ref
package uninstall <id|name>delete the installed files (stays in the list)
package repo add <link> [--ref <tag|branch|sha>] [--name <name>] [--entry <file.py>] [--category <word>] [--no-confirm]
package repo remove <id|name>uninstall and forget it completely
package repo listwhere every package comes from
package source add <link|folder|file.source|name> [--ref <tag|branch|sha>]
package source remove <id|name>forget a catalog (added packages stay)
package source update [id|name]re-fetch catalogs
package source listregistered catalogs
package search [text]packages offered by the catalogs
package reloadrescan the packages folder
package doctorruntime + per-package health
Example 
package repo add https://github.com/mvt-project/mvt
package install mvt

Who am I whoami / wai

CommandDescription
waiRun the who-am-I skill: voice and camera together
wai voiceWhose voice last spoke
wai cameraWho the camera sees

whoami is the same command but only works in the Triton Shell; in PowerShell, cmd and bash tabs whoami stays the operating system's own, so use wai there.

Central Module Opener cmo

CommandDescription
cmo start <app name>Open an installed app by its exact name; case and spacing don't matter (aliases: cmo launch, cmo open)
cmo start <app name> -cmOpen the app whose name is closest to what was typed, e.g. cmo start camra -cm opens Camera
cmo whereis <app name>Print where an installed app is, without opening it
cmo whereis <app name> -cmSame, for the app whose name is closest to what was typed
cmo start-loggingRecord every app CMO opens in its open log
cmo stop-loggingStop recording; what is already logged is kept
cmo statusWhether the open log is recording, and where the file is (plain cmo does the same)
