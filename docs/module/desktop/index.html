Desktop.

The Desktop is Triton's main screen: the grid of app and file tiles, the bottom bar, the launcher, widgets and the wallpaper. Every app you open in Triton starts from here.

This page is an overview of the Desktop module. Pages for each Desktop component will be listed under Desktop in the sidebar.

What the Desktop is

The Desktop is one of Triton's built-in modules, in the package echelon.desktop. It starts when you sign in and draws the Desktop on every screen.

You get here by booting a Desktop boot profile, which Triton does by default. See Boot profiles.

It is the shell the rest of Triton runs in:

  • It lays out the tiles for your apps and files, and opens them.
  • It owns the bottom bar, the launcher, the widgets and the wallpaper.
  • It saves how your desktop is arranged. Installed apps are shared by every user; where their tiles sit is kept per user.

The Desktop is part of Triton, not an app. To put your own app on it, see Making apps.

Components

The Desktop is made of these parts:

ComponentWhat it does
Tile gridThe grid of app, file and folder tiles. Drag tiles to rearrange them, or drop files on it from outside Triton.
Bottom barA button for each open app. Apps can add their own items to its right-click menu: see Bottom-bar menu.
LauncherSearch, your pinned apps, all programs and the power menu.
WidgetsPanels that live on the Desktop, on a grid of their own above the wallpaper. They can sit on any screen.
WallpaperThe Desktop background. A themed wallpaper is a grayscale image that Triton recolours to match the active theme.
Snap AssistDrag a window to a screen edge or corner to snap it to half or a quarter of the screen.
NotificationsMessages from Triton and from apps, and the notification centre that keeps them.
ScreensEach screen shows a Desktop of its own.

Tiles

The tiles on the Desktop come from three places:

  • Apps. Every folder in echelon/desktop/container/applications/ is an app and gets a tile, named after the folder.
  • Your files. Every file in your own desktop folder, echelon/users/<user>/desktop/, gets a tile.
  • Folders and the Trash. A Desktop folder holds shortcuts to tiles. The Trash is your own and holds the real files.

Drop files on the Desktop from Explorer, a browser or another program, and Triton copies them into your desktop folder. The original stays where it was, so a drop in the wrong place does no harm.

Only your own files can go in the Trash. To remove an app, uninstall it.

Desktops and screens

A desktop is a named set of tiles. A screen is only where a desktop is shown. Each desktop has an id:

IdDesktop
d0The main desktop.
d1, d2, …Saved desktops, for example the one on a second screen.
t-…Temporary desktops. They are never saved and are gone when you sign out or quit Triton.

Triton saves each desktop's tiles as you change them. File paths are saved in a portable form, so a desktop still works when Triton's main folder moves to another drive or machine.

A new user starts from the default preset: an arrangement of tiles that ships with Triton. Apps installed later are added to the free cells as usual.

Keyboard

While the Desktop is the active surface (click an empty spot on it), these keys work on the tiles:

KeyAction
↑ ↓ ← →Move the selection to the nearest tile in that direction. With nothing selected, the first key picks a tile from that edge.
EnterOpen the selected tile or tiles.
EscClear the selection.
Win+DHide all apps and show the Desktop. Press it again to bring them back. Windows and Linux.

The arrow keys and Enter only act on the Desktop while it is in front. In an app window they work as usual.

For every key Triton takes over, and how to add, remap or block keys of your own, see Key Interception.

Snap Assist

Drag a window to an edge or corner of the screen. Triton shows where it will go, and snaps it there when you let go:

Drag toThe window fills
Left edgeThe left half
Right edgeThe right half
Top edge, middleThe whole screen
A cornerThat quarter of the screen

Where the Desktop keeps its files

All in Triton's main folder, echelon:

PathHolds
echelon/desktop/container/applications/Installed apps, one folder each. Shared by every user.
echelon/users/<user>/desktop/Your own desktop files. Each one is a tile.
echelon/users/<user>/parallax/Your desktops: the tiles of each one and where they sit.
echelon/desktop/default.jsonThe default preset for new users.
echelon/desktop/background.jsonWallpaper settings.
echelon/desktop/modular-addon/Widget jars.

Triton writes these files itself. Don't put your own files in parallax/: put them in your desktop folder.
