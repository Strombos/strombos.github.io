Anti Motion Sickness.

Some of Triton's animations move the whole view: the camera flies in at sign-in, the Media Player's reels spin. If movement like that makes you dizzy or sick, Anti Motion Sickness turns it off, one feature at a time or all at once.

Find it in Settings → Accessibility → Anti motion sickness. It starts off.

Turning it on

  1. Open Settings and choose Accessibility.
  2. Under Anti motion sickness, tick Enable all, or tick only the options you want.

A change applies at once. The one exception is the sign-in intro, which uses your choice the next time the sign-in screen opens.

The options

OptionWhat it does
Login intro: keep the camera stillThe sign-in intro plays in place: no panning, tilting or zooming on the way to the card, and no dive or spin when you unlock. Takes effect the next time the sign-in screen opens.
No reel animationThe Media Player's cassette reels stay still while music plays. Reel speed is locked at zero; your own speed comes back when you turn this off.

More options will be added here as Triton gets more animations that can be calmed down.

Enable all

Enable all sits above the options and turns every one of them on, including options added in later versions of Triton. You can still switch them one by one afterwards.

  • Ticked means every option is on.
  • SOME ON beside it means only some are on. Click it to turn them all on.
  • Not ticked means none are on. Untick it to turn every option off.

Enable all never claims more than is true: as soon as you turn one option off, it shows SOME ON instead.

Locked controls

While an option is on, the controls it calms are locked. For example, with No reel animation on, the Media Player's reel speed can't be changed. Hover over a locked control to see why:

Anti motion sickness is on, so this can't be changed. Turn it off in Settings → Accessibility.

Where it is saved

Anti Motion Sickness is saved in Triton's settings file, settings.properties, not in your own user folder. It counts for everyone who uses this Triton, because the sign-in intro plays before anyone has signed in.

KeyOption
motion.allEnable all
motion.login_intro_stillLogin intro: keep the camera still
motion.no_reel_animationNo reel animation

An option with no key of its own follows motion.all. That is how an option added later is already on if you chose Enable all.
