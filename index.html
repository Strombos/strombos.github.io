What is Triton

A desktop shell you shape yourself.

Triton is a desktop environment that runs on top of your operating system. It replaces the usual desktop with tiles, apps, and widgets you arrange and swap however you like. Bring in the programs you already use, add Triton apps, or change the pieces yourself — most of it is open to you.

The idea

A vision to create your own space — customize it, play around, and make the space yours.

— Deon
  • Your layout

    Tiles, docks, and widgets you place where you want them, on one screen or many.

  • Your apps

    Launch the programs already on your machine, install Triton apps, or edit and build your own.

  • Goes with you

    Runs portably from a USB drive with your setup intact, or installs to your machine for speed.

Note: Triton is a desktop environment that runs on top of your operating system. It doesn't replace your OS login or sandbox the programs you run, so your computer's security still comes from the OS, not from Triton.

  • 4 GB is the floor. Triton can use up to 60% of RAM, so on 4 GB it runs but may slow down under heavy use.

How to run

How to start Triton

Triton runs on Java 21 or higher, either installed on the machine or carried in a folder next to triton.jar. triton.jar itself opens with a double-click, even where only Java 8 is installed. Pick whichever way suits you.

Triton OS is a live system: write the image to a USB stick once, then boot your computer from it.
  1. Option 1 · Open it

    Double-click triton.jar

    Open the downloaded file like any other program. If it opens in an archive tool instead, right-click it and choose Open with → Java.

    On macOS the first launch may be blocked. Right-click the file, choose Open, then confirm.
    Only Java 8 on this machine?

    The jar still opens. A small Java 8 launcher looks for Java 21 or higher and moves Triton onto it. It checks a jdk… or jre… folder right next to triton.jar first, then any Java 21+ installed on the machine. If it finds none, it tells you what to install.

    To fix it, pick one of the three ways under Get Java 21 or higher below.

    Right-click triton.jar and choose Open With → OpenJDK Java Runtime. If Java isn't listed, see Get Java 21 or higher below.

    Start it from your desktop session: Triton needs a graphical desktop (tested on Ubuntu Desktop).
  2. Option 2 · Command line

    Run it from a terminal

    Open a terminal in the folder where you saved triton.jar. Handy for seeing startup messages or passing launch options.

    Java on your PATH 
    java -jar triton.jar

    This uses whichever java comes first. Check it with java -version: it must say 21 or higher. If it doesn't, use way 3 under Get Java 21 or higher.

  3. Java · three ways

    Get Java 21 or higher

    Triton needs Java 21 or higher. Java 8 or 17 is not enough. Any one of these ways works.

    1 · Simplest

    Install a newer Java

    Download and install a JDK 21 or newer from one of these official pages:

    Eclipse Temurin 21 · Adoptium Oracle Java · JDK 21 Microsoft Build of OpenJDK

    On Windows, pick the x64 installer (.msi or .exe).

    On a Mac, pick the aarch64 / arm64 (Apple silicon) .pkg. Triton on macOS needs an arm64 JDK; the x64 one won't do.

    On Ubuntu, the package manager is quicker:

    sudo apt install openjdk-21-jre

    Then double-click triton.jar again. It finds the new Java by itself.

    2 · No install

    Put a portable JDK next to triton.jar

    From the same pages, download the archive (.zip.tar.gz) instead of the installer and unpack it into the folder that holds triton.jar:

    Triton\
├─ triton.jar
└─ jdk-21.0.5+11\
   ├─ release
   └─ bin\
      └─ java.exe
     
    Triton/
├─ triton.jar
└─ jdk-21.0.5+11/
   ├─ release
   └─ bin/
      └─ java
     
    Triton/
├─ triton.jar
└─ jdk-21.0.5+11/
   └─ Contents/
      └─ Home/
         ├─ release
         └─ bin/
            └─ java
    • Put it right next to triton.jar, not in a subfolder.
    • Its name must start with jdk or jre. The name it unpacks with is fine.
    • This file must exist inside it: bin\java.exebin/javaContents/Home/bin/java.
    • It must be built for your system (Windows x64Linux x64 or aarch64macOS aarch64). Keep its release file: the launcher reads it to check.

    A double-click uses this folder even when the machine only has Java 8, so a USB drive can carry its own Java. The Demo Bundle will include one later.

    3 · Terminal

    Start it with a specific Java

    Open a terminal in the triton.jar folder and use the full path to that Java's java:

    & "C:\Program Files\Java\jdk-21\bin\java.exe" -jar triton.jar

    That's PowerShell; in Command Prompt, leave out the &. With the portable folder from way 2:

    .\jdk-21.0.5+11\bin\java.exe -jar triton.jar
     
    /usr/lib/jvm/java-21-openjdk-amd64/bin/java -jar triton.jar

    With the portable folder from way 2 (if it came out of a zip, run chmod +x jdk-21.0.5+11/bin/java once first):

    ./jdk-21.0.5+11/bin/java -jar triton.jar
     
    /Library/Java/JavaVirtualMachines/temurin-21.jdk/Contents/Home/bin/java -jar triton.jar

    With the portable folder from way 2:

    ./jdk-21.0.5+11/Contents/Home/bin/java -jar triton.jar

    Swap the path for wherever your Java 21 lives. To see which version a java is, run it with -version instead of -jar triton.jar.

    4.
  4. Option 1 · USB stick

    Boot from a USB stick

    For triton-os-amd64.iso. Writing the image erases everything on the stick.

    1. Write the ISO to a USB stick (8 GB or larger) with balenaEtcher or Rufus.
    2. Restart with the stick plugged in and pick it from your computer's boot menu (often F12, F11 or Esc during startup).
    3. Triton OS boots to the setup wizard. If the stick doesn't show up, turn off Secure Boot and try again.
  5. Option 2 · Virtual machine

    Try it in VirtualBox

    No USB stick or restart needed. This is how Triton OS has been tested so far.

    1. Create a new VM: type Linux, version Debian (64-bit).
    2. Give it at least 4 GB of memory (6 GB tested) and 2 or more CPU cores.
    3. Attach triton-os-amd64.iso as the optical drive and start the VM. It reaches the setup wizard in about 75 seconds.
    6.

Triton creates an echo folder next to triton.jar on first launch, or uses the one from the Demo Bundle if you extracted it there. Keep the two together — on a USB drive, that folder is your whole setup.

Triton OS runs from memory. Without persistence, anything you save is gone when you shut down.
